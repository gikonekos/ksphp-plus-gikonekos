[1. 게시글 링크 이미지 썸네일 기능 (js/imgthumb.js)]
------------------------------------------------------------
게시글 본문의 URL이 실제로 존재하는 이미지 파일(기본 지원 확장자:
jpg/jpeg/png/gif/webp/bmp/avif/svg)을 가리키는 경우, 해당 URL
오른쪽에 썸네일을 자동으로 표시합니다.

  ・기존 js/upthumb.js(특정 업로더의 알려진 디렉터리 구조 전용)와는
    독립된 별도 파일입니다. 둘 다 동시에 사용할 수 있습니다.
  ・표시 전에 HEAD 요청으로 URL의 실제 존재 여부와 Content-Type이
    image/*인지 확인한 후 표시합니다(확장자만으로 판단하지 않습니다).
  ・게시 폼 옆(기존 "Uploader thumbnails"와 같은 줄)에
    "Link thumbnails" 체크박스가 추가됩니다. On/Off 상태는
    브라우저의 localStorage에 저장되며, 서버로는 전송되지 않습니다.
  ・대상 확장자 필터링은 개인 환경설정 화면(?setup=1)에 자동으로
    추가되는 체크박스 그룹에서 설정합니다. 기본값은 전체 선택입니다.
    이 역시 localStorage에만 저장되며, 설정 폼 전송에는 포함되지
    않습니다.

  [설치 절차]
  1. js/imgthumb.js를 js/ 디렉터리에 배치.
  2. sub/template.html을 교체(<head> 안의 스크립트 로드 부분에
     <script src="js/imgthumb.js" defer></script> 한 줄이
     추가되어 있습니다).
  3. bbs.php를 교체(아래 설명하는 window.KSPHP_LANG 삽입 처리 포함).
  4. language/english.txt・language/japanese.txt를 교체
     (신규 키 12개 추가 완료. 기존 키는 변경하지 않았습니다).
  별도 설정은 필요 없습니다. 파일을 배치하는 것만으로 활성화됩니다.

[2. JavaScript 다국어 지원 (window.KSPHP_LANG)]
------------------------------------------------------------
지금까지 게시판 본체(PHP 템플릿)는 언어 파일(language/*.txt)로
다국어 지원이 되어 있었지만, js/ 이하 스크립트 내의 문구(버튼
레이블 등)는 대상 밖으로, 항상 고정 표시였습니다.

이번에 bbs.php 측에서 언어 파일 내용을 JSON화하여, HTML의
<head> 안, 다른 스크립트보다 먼저

    <script>window.KSPHP_LANG = { ... };</script>

형태로 삽입하는 구조를 추가했습니다. 이를 통해 js/ 이하의
스크립트에서

    window.KSPHP_LANG.키_이름

형태로 language/*.txt에 정의된 문구를 직접 참조할 수 있습니다.
(예: window.KSPHP_LANG.MAKE_LINE_BREAKS_BTN)

  [이번에 이 구조에 대응시킨 파일]
  js/ayashiibreaker.js, js/upthumb.js, js/imgthumb.js, js/vanish.js,
  js/admin.js의 5개 파일.

  [향후 새로운 JS 파일을 다국어 지원시키는 경우]
  1. language/english.txt・language/japanese.txt에 키와 한국어/영어
     각각의 문구를 추가한다(기존 키・값 형식에 맞춰 KEY=값의 한 줄
     형식으로).
  2. JS 파일 측에서 `window.KSPHP_LANG.키_이름`을 참조한다. 아직
     로드되지 않은 경우를 대비해
     `(window.KSPHP_LANG && window.KSPHP_LANG.키_이름) || "기본값"`
     형태로 대체값(fallback)을 준비할 것을 권장합니다.
  3. 서버 측(PHP) 변경은 필요 없습니다(window.KSPHP_LANG은 모든
     페이지에서 자동으로 출력됩니다).

[동작 확인 완료 사항]
------------------------------------------------------------
- 전체 PHP 파일: php -l로 구문 오류 없음
- 전체 JS 파일(수정・신규분): node --check로 구문 오류 없음
- language/english.txt・language/japanese.txt: 키 개수 일치(216개),
  중복 키 없음
- 게시판 메인・과거 로그 검색・트리 보기・관리자 로그인
  (GET/POST)・개인 설정 화면・관리 메뉴의 모든 경로에서, 한국어
  기준 원본인 일본어・영어 두 LANGUAGE_FILE 설정 모두 HTTP 200,
  {PLACEHOLDER} 렌더링 잔여 없음, window.KSPHP_LANG이 유효한
  JSON으로 출력되는 것을 확인했습니다.

[설치 완료 후 반드시 할 일 (중요)]
------------------------------------------------------------
설치가 끝나면 install/ 디렉터리를 통째로 삭제하십시오.

install.php는 누구나 설치 작업을 할 수 있도록 인증 없이 동작합니다.
따라서 설치 후에 남겨 두면 제3자가 다음 정보를 얻을 수 있습니다.

  - 서버상의 게시판 절대 경로, 버전, 쓰기 권한, 제목
  - conf.php 설정값의 대부분 (관리자 비밀번호와 키는 제외)
  - install/backup/ 안의 로그 (서버 절대 경로와 설치 파일 목록)

install/index.html과 install/backup/index.html이 포함되어 있어
디렉터리 목록 표시는 억제되지만, 이는 목록 억제일 뿐 접근 제어가
아닙니다. 파일 이름을 아는 상대는 여전히 읽을 수 있습니다.
삭제만이 확실한 대처입니다.

참고로 _setup.php(관리자 비밀번호 설정 도구)는 사용 후 스스로
이름을 바꾸는 구조를 가지고 있습니다. install.php에는 이 구조가
없으므로 수동 삭제가 필요합니다.
