## 導入手順
1. ダウンロードしたZIPファイルを展開する
2. conf.phpを開いて設定する
3. FTPクライアント等でサーバーへファイルをアップロードする（他のファイルと混ざらないよう専用ディレクトリを作るのがおすすめです）
4. 以下のパーミッションを設定する
5. ブラウザで`_setup.php`（パッケージに同梱の独立ツール。conf.phpやinstall.phpとは別物）にアクセスし、管理者パスワードを設定する。完了するとツールは自動でリネームされます — 新しい名前・URLを控えておいてください。
6. *（現在は不要 — 管理者パスワードはconf.phpではなく`_setup.php`が専用ファイルへ書き込みます）*
7. ブラウザでbbs.phpにアクセスし、投稿できるか確認する
8. ログファイル（bbs.log、log/内のファイル等）のURLにブラウザでアクセスし、見えてしまわないか確認する（見える場合は.htaccess等で隠してください）

## トラブルシューティング
### 既存サイトのアップグレード（管理者パスワードの移行）
RC8以降、管理者パスワード（ADMINPOST/ADMINKEY）はconf.phpの外、install.phpで上書きされることのない固定名ファイル`local.php`に置かれます。install.phpは既存conf.phpに空でないADMINPOSTがあることを検出すると、**旧パスワード**（本人確認）と**新パスワード**の入力を求める移行フォームを表示します。ADMINKEYは自動的に引き継がれます。

- 旧パスワードの確認に成功すると、`local.php`が書き込まれ、インストールが続行されます。
- 確認に失敗すると、**インストール全体が中止されます**（ファイルは一切インストールされません）。
- 旧パスワードを忘れてしまった場合は、サーバー上の既存conf.phpの`ADMINPOST`を手動で空文字列にしてください。install.phpは新規インストールとして扱い、`_setup.php`経由で新しいパスワードを設定できます。

## 推奨パーミッション設定
パーミッションの設定を誤ると、不具合やデータ漏洩（IPアドレス・リモートホスト等）の原因になります。

```
[ファイル構成]
|-- bbs.cnt   600（書き込み可）  参加者リスト記録ファイル（空のテキストファイル）
|-- bbs.log   600（書き込み可）  ログファイル（空のテキストファイル）
|-- conf.php  644（読み取り専用）設定ファイル
|-- bbs.php   644（読み取り専用）掲示板本体スクリプト
|-- readme.md                    このファイル
|-- vanish.js                    ワードフィルタリング用スクリプト
|
+-- archive/  700（書き込み可）  ZIPアーカイブ保存ディレクトリ
+-- count/    700（書き込み可）  カウンター出力ディレクトリ
+-- log/      700（書き込み可）  メッセージログ（生ログ）保存ディレクトリ
+-- sub/      755（読み取り専用）サブモジュール
    |-- bbsadmin.php    644      管理モジュール
    |-- bbslog.php      644      ログビューアモジュール
    |-- bbstree.php     644      ツリー表示モジュール
    |-- phpzip.inc.php  644      ZIPファイル作成ライブラリ
```

PHPがApacheモジュールとして動作している場合、bbs.phpは644（読み取り専用）で構いません。CGIとして動作している場合は755（実行可能）に設定してください。
