install

KuzuhaScriptPHP+ installer directory.

Delete this directory once installation is complete. It contains the installer and its backups and logs, which expose server paths and configuration values to anyone who can reach them.

設置が終わったら、このディレクトリごと削除してください。 インストーラーとそのバックアップ・ログが入っており、サーバーの パスや設定値が第三者に読まれる可能性があります。
